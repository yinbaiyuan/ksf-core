# 知识、档案及其他管理职责说明

六类管理职责分别由能力、项目、知识、档案、收件箱、人设搭档承担。能力对象生命周期由 ability-maintenance，知识组织由 knowledge-organize，档案主件与版本由 archive-maintenance，输入分流由 inbox-triage，人设长期维护与扩展由 persona-maintenance 持有。项目整体归档与恢复由 project-acceptance 持有，工程保持原位。

这些基本功决定专业归属、条件和处理流程；程序提供确定性读写与校验。用户目录中的导航、分类、模板和已确认事实属于实例输入。本文是说明入口，不作为额外业务规则源。

默认知识与档案模板位于 distribution/template，具体采用方式由所属基本功说明。既有实例内容和不同框架保留其原有来源；根 USER/BOT 与详细人设通过入口和人设管理连接，不成为新能力对象类型。
