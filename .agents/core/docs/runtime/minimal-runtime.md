# 最小运行链说明

入口程序先选择初始化、孵化或正常模式；正常模式只选择Runtime，再按其 `#persona-route` 与人设路由的两个 `+` 文件引用提供人设路由、USER/BOT原文，共四项基础内容。ability-route、project-route保留无前缀精确依赖，Runtime在使用前经现有extras按需取得全文。人设路由在业务判断前核对采用基础卡，详情与维护按需交人设管理。对象保护名单和加载关系分别由schema与references表达，入口程序不维护专业路由加载名单。

runtime 组织目标和任务连续性，项目路由补必要事实，能力路由按现行方法安排承接。全局协作和普通搭档均未命中后，基本功路由进行一次游离基本功匹配与执行。六类管理职责按需采用，其专业基本功直接负责本领域保存和检查。

[Runtime与上下文完整机制](work-context.md)串起职责、状态与恢复；[运行链](routing.md)解释对象连接，[context](../cli/context.md)解释程序响应。结构检查、程序回归、真实模型效果及发行分别产生证据。

工作连续性由 Runtime 的当前绑定保持；context 装配服务按现有引用图提供每轮有效清单及正文增量，完整消费后才更新指纹缓存。Hook 提供短清单，压缩/恢复时换代重读当前集合，不建立任务历史或改写项目进度。实现接口见 [context](../cli/context.md#当前工作与增量正文)。
