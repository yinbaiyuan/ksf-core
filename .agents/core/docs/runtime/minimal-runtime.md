# 最小运行链说明

固定 Core 对象为入口协作、runtime、ability-route、project-route，共四个。入口程序先选择初始化、孵化或正常模式；正常模式一次提供基础 USER/BOT 以及三项运行定义。

runtime 组织目标和任务连续性，项目路由补必要事实，能力路由按现行方法安排承接。全局协作和普通搭档均未命中后，基本功路由进行一次游离基本功匹配与执行。六类管理职责按需采用，其专业基本功直接负责本领域保存和检查。

[运行链](routing.md)解释对象连接，[context](../cli/context.md)解释程序响应。结构检查、程序回归、真实模型效果及发行分别产生证据。
