# 每轮对话与路由归档

一个 Codex 聊天对应一个任务，与业务项目、项目任务检查点分别识别，不按 cwd、时间或标题推断项目/能力。长期档案是可核对原件，不是自动记忆或项目事实。

已接入采集时，当前 Agent 使用 UserPromptSubmit 提供的原生 turnId，先调用只读 task declare 明确 policy 和最小安排；路由确认或改变、新采用能力、交付/中断前更新，复用有效安排，不逐工具上报。完整参数见 [task CLI](../cli/task.md)。不能自行造原生轮次 ID，不能按时间猜配旧路由。

普通“只讨论、只读、不保存”仍限制业务资产与检查点写入。启用归档已授权自动采集基线后的普通对话，不依赖本轮 Agent 声明或路由上报；声明缺失不应导致用户原话和最终答复成为空记录。明确“本轮不记录”声明 exclude，“不记录对话”声明 pause，明确恢复声明 resume。规划模式通过只读回执表达，Agent 不为此直接写文件。无可靠路由时只声明 policy，保持未上报。

没有声明的轮次如果出现对话记录限制词组，先保守保存无正文 pending 占位并标记策略待确认，不把引文直接判成永久排除；当前轮次声明可澄清，已经延续至后续轮次的待确认限制须明确 resume。明确排除、聊天暂停和未取得用户输入的轮次不采用默认采集。旧版普通 pending 占位通过正常补采修复，不为旧轮次补造声明或路由，也不跨越启用基线与明确排除。

report 沿用现有项目、能力规则，记录精确来源、路径、版本、摘要、采用阶段和引用项目；reason 只写可向用户说明的选择依据，不索取隐藏思维链。固定入口单列，来源变化不改绑。

采集声明的inputScope绑定已收到的输入版本。新增限制未被新范围覆盖时立即保守pending，旧回执重放不扩大许可；Hook范围缺失或同轮新增输入后，以只读task input补核，不猜造值。旧声明的范围按可核实的原位置/签名时间保守兼容，归档只保存无正文的覆盖证据。当前工作绑定和按需加载不自动产生采用声明，路由不必每轮重新执行。

Hooks 登记原生边界并在完成、中断、压缩前读取可见消息；Web/CLI 补采延迟刷盘。工具输出仅核验回执和读取交互问答，系统/开发指令、隐藏推理与自动注入不归档。先检查策略再存正文；排除清空本轮正文及修订副本并留下 tombstone，补采不跨越排除。最终答复未刷盘时重试，再标待补采，不伪造完成。

原生工具创建的用户所有会话，其首轮任务可能以 codex_app.create_thread 的原生工具回执出现。只有已核对的 agent_created_thread 元信息、app_tool_create_thread 原生边界和完整 codex_delegation 结构共同匹配时，适配器才将原输入按 delegated_input 保存，带来源线程及转发性质；不冒充用户手工输入。普通工具结果、引用相同包装、其他触发或内部 worker 不因此进入用户正文。排除、暂停及启用基线继续优先，解析器升级通过版本化游标重新核对原件，不手工改档案正文。

启用只覆盖未来新轮次，旧 v1 路由不按时间迁移。采集失败不阻断原任务。关闭 Web 后 Hook/CLI 独立工作，没有后台服务或网络上传。

分叉归档使用与chat计数一致的原生毫秒时间和已核实创建边界，只记录子聊天新增轮次；父关系保存匿名任务标识，通过原档案查看，不复制父正文和路由。缺少可靠创建时间时不猜测接入范围，旧重复项不自动清除。

适配器按完整行严格解码，合法分块Unicode保持原样。坏记录按来源/轮次定位；无法确认新边界时停止猜配后续消息，下一可靠边界恢复。尾部尚未刷完只进入sourceIssues，不污染无关已完成历史轮次；缺口不会因读取失败被当作不存在。

## 主归属与关联对象

每次明确安排使用一个 ownership，目标可为项目、知识单元、能力或档案保存单元；relatedTargets 保存关联对象，不建立聊天归属。知识入口按 `知识/knowledge.md` 的明确导航核验，不依赖对象 ID、版本或统一文件名。只讨论、尚未保存正文也可归到已有具体单元；待确定时不创建主题。旧 project/references 只在读取时映射，历史原件不改写。新旧字段不能在同一次输入混用。

归属导航聚合全部历史主归属，聊天仍保存一份，完整轮次仍可查看其他目标的轮次；关联不参与计数或默认定位。知识失效保留精确路径和历史名称，不按同名改绑。task-targets API、--target 及 targetContext 的查询契约由 [task CLI](../cli/task.md) 持有。

待创建目标与显式绑定随原轮次 targetFacts 保存，使用全局目标锁检查跨聊天的预期版本；完整目标快照与声明同文件发布，不另建任务正文。采集重放恢复索引及别名；重复声明不增加事实，冲突不覆盖并标出缺口。关闭 routing 不接受新的目标事实；排除先于保存，明确排除后清除该轮目标事实。其他允许轮次已明确引用的身份可继续从其快照恢复。历史节点的待创建与来源状态保持当时事实，后续绑定仅作查询附注。
