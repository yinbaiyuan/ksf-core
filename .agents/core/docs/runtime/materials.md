# 资料采用说明

资料进入任务的通用边界见[能力路由](../../abilities/competencies/ability-route/competency.md#交回-runtime)。各协作、搭档、基本功和数据包在自身定义中说明用途、入口或限定范围、读取条件与缺失处理；[Runtime](../../abilities/partners/ksf-runtime/partner.md#衔接专业工作)负责交接与结果接续。

正常业务采用当前输入/指定材料、必要项目事实和已采用能力明确约定的资料。显式知识任务可以沿其导航进入相关原文。程序和文件工具提供读取事实，不把“发现”“已读”“采用”“已使用”合并为同一状态。

知识组织、项目接入、档案维护和人设维护分别说明各自的材料处理方法。原件和正式主件保持其领域归属；基础USER/BOT由人设路由声明文件引用，经公共展开器提供原文，再由人设路由在业务判断前核对采用，详情按人设管理按需加载。
