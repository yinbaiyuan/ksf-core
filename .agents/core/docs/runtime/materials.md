# 资料采用说明

资料进入任务的条件、来源核对及缺口传播由 [runtime](../../abilities/partners/ksf-runtime/partner.md#资料采用)持有。各协作、搭档、基本功和数据包在自身定义中说明用途、入口或限定范围、读取条件与缺失处理。

正常业务采用当前输入/指定材料、必要项目事实和已采用能力明确约定的资料。显式知识任务可以沿其导航进入相关原文。程序和文件工具提供读取事实，不把“发现”“已读”“采用”“已使用”合并为同一状态。

知识组织、项目接入、档案维护和人设维护分别说明各自的材料处理方法。原件和正式主件保持其领域归属；基础 USER/BOT 在入口固定提供，详情按人设管理按需加载。
