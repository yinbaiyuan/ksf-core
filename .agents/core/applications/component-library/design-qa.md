## 五项视觉检查

- 字体：沿用应用既有字体。标题16px/24px、600，导语12px/20px，数量11px，编号40px且低对比度；长分类名/匹配数量允许自然换行，五种窗口宽度无裁切。
- 间距：卡内16px，网格16px；正文宽480/720px切换1/2/3列。最小高度160px遵循已批准方案，较概念图约145px更高，属于明确约束而非未处理差异。
- 颜色：现有KSF浅/深语义色；实窗主色分别#005fb8/#60cdff，主题原件SHA保持；薄边、淡主色悬停与克制阴影已核对。
- 图标/图像：使用已依赖的Lucide真实图标，经SDK Icon渲染；图中少量定制图形由同语义标准图标承接，保留为P3差异。卡片没有照片、纹理或其他需生成的图像资产；概念图未作为界面贴图。
- 文案：14个真实分类名称和匹配数量；编号固定01–14，筛选不重排编号；首页简短导语按分类ID维护，分类页完整职责说明保留。重复“查看XX”及独立页脚已移除。
