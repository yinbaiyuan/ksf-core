## 应用使用 SDK 的组织

应用级控制器集中解析既有链接，持有本窗口主题、共享筛选、目录展开与窄窗状态。目录和总览读取同一查询结果；返回总览保留筛选，筛选不强制关闭当前详情。侧栏常驻搜索与结果/筛选工具行，交付情况、来源和类型在窗口内 Popover 中展开；条件重置保留搜索，侧栏重置清除全部条件并将焦点还给搜索。窄窗沿用 Drawer 自带标题，避免重复身份信息。页面不维护第二份组件清单或来源状态。

外壳使用 View／AppLayout／SplitView／ScrollArea，工具栏继续走 WindowToolbar；目录使用 NavigationList、SearchField 和 Select，宽度不超过660px时使用窗口内 Drawer。分类与实览使用 Grid／Card／Statistic，详情使用 Breadcrumb／Tabs／Anchor，API 与来源使用 Table／DescriptionList／Accordion。普通操作与反馈复用 Button／Link／Tag／InlineAlert／EmptyState／Skeleton。

代码阅读区是应用私有的 CodeView，由原生 pre/code、SDK ScrollArea、Button 和反馈组件组合；CodeBlock 仍为候选，应用不声明该公共导出。复制失败可选择原文，过期复制结果在换例或卸载后忽略。

应用布局和文档样式与预览画布分开。preview.css 保留构建120的示例尺寸与补充主题演示规则；应用控件不覆盖 SDK 皮肤。示例锚点拥有窗口唯一 DOM ID，并只操作所属正文滚动容器。

`node --test library-model.test.ts` 核对旧链接、正式与候选路由、页签和筛选初始条件。完整示例源码和真实预览注册仍由 check/build 逐例核验。

目录与正文由 SDK SplitView 分栏，侧栏默认260px，可拖动或用方向键调节到240–420px；正文至少360px，双击分隔恢复默认。实际宽度小于约束总和时由分栏组件限界，窄窗使用原有 Drawer，保留同窗口的侧栏偏好宽度。只让目录列表、正文和代码区域各自滚动，应用挂载边界截住预览溢出，避免带动宿主外层滚动。目录通过 NavigationList 原生 style 属性使用透明底色并移除重复边框，行选中、悬停和键盘反馈沿用 SDK。短窗筛选弹层仅滚动条件区，底部操作保持可见。应用自有滚动区域在滚动时显示滑块，停止约800ms后淡出；保留原生滚动及固定轨道占位，窗口停用或卸载时清理活动指示。减少动态设置下直接切换显隐，高对比模式保留系统滚动条；示例画布中的公共组件保持各自默认行为。


组件总览首页只展示统计与分类入口，不挂载实览或完整示例源码。分类与详情沿原有链接参数进入；分类页每项一个基础实览，重型预览和完整详情按路由加载。筛选全窗口共享，分类匹配数限定当前分类。目录启用 NavigationList.selectBranches，名称进入分类、独立箭头只展开，窄窗选择后关闭目录并将焦点移至正文。
