# KSF能力

直接查看和维护当前实例的原件，不建立应用私有正文数据库。应用仅在用户明确保存时写入，能力沿公共对象契约派生，知识沿原文件版本保存；冲突保留草稿，浏览器会话保留未保存输入。

能力对象的状态与效果验证分开；知识内容及认知框架由人决定，普通新记录不自动变成认知主题或能力。跨域来源沿显式链接打开项目、能力、知识或飞轮；准备给 Agent 的任务草稿不等于发送或采用。

构建：`node build.mjs`。验证范围以项目中的实际验收记录为准。

左下角「打包能力」支持跨类型多选当前有效能力，个人能力可直接打包。预览包含的能力与自动依赖后下载 `.ksfabi` 文件，可在能力商店导入；详情页「打包此能力」会预选当前项。只打包已保存内容，个人原件及设置保持不变。单包压缩上限20MiB、资源24MiB、5000个文件；超限需整理资源或缩小范围。
