# 基本功专业检查表

归属：基本功设计。逐项记录通过、问题或不适用，附原文/案例位置及影响。P0 阻止对应方法使用；P1 影响稳定性；P2 影响易用和成本。严重度依据实际后果，不按数量凑分。

| 编号 | 检查问题 | 失败证据 | 修正方向 |
| --- | --- | --- | --- |
| M1 P0 | 是否有独立且可检查的结果 | 定义覆盖所有工作或只是无意义单步 | 重定结果与粒度 |
| M2 P0 | 核心判断是否有可取得的依据 | 凭名称生成专家标准，假设冒充经验 | 回到来源或建立验证假设 |
| M3 P0 | 证据、判断、动作是否连得起来 | 只有理论名词、“深入分析”或工具名 | 补上区分条件及对应动作 |
| M4 P0 | 输入不足能否避免无依据结论 | 缺口被默认补造 | 补证、保留未知或停止依赖步骤 |
| M5 P1 | 主结构与不确定性是否匹配 | 固定题套开放发散，诊断题直接下结论 | 调整自由度及结构 |
| M6 P1 | 分支和结束能否判定 | 无限反思、固定轮数或“直到满意” | 定义结果条件及收敛去向 |
| M7 P1 | 质量标准是否检查专业结果 | 只数章节、字数或主观形容词 | 写出结果差异与失败信号 |
| M8 P1 | 能否迁移并识别不适用情形 | 只会复制样例 | 扰动输入、补边界和反例 |
| M9 P0 | 支持能否实际取得和使用 | 不存在的 CLI、来源或隐式加载 | 核实入口，提供缺失处理 |
| M10 P1 | 数据与职责归属是否清楚 | 保存任务正文、复制搭档职责 | 保留原件，缩回专业方法 |
| M11 P1 | 参数是否真正改变方法 | 只列字段，不消费或擅自记偏好 | 指向消费步骤，无需求则删除 |
| M12 P1 | 验证是否有实际结果 | 预期冒充通过，一题代表全部效果 | 保存产物并限定结论 |
| M13 P2 | 每段是否影响判断或产物 | 大量常识、形容词、重复纪律 | 删除或用短例说明 |
| M14 P1 | 能否自举而不自动越权 | 候选自评后覆盖现行规则 | 保留基线，按授权换入候选 |

审查报告先给是否可用和最重要缺口，再逐项列证据。重构把问题映射到新的规则、删除或边界调整，不机械保留旧章节。通用 YAML、加载和工艺检查需要时使用能力诊断与现有程序，不在这里复制另一套完整审计。
