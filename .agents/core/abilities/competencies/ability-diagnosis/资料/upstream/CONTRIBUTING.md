# Contributing to better-skill

Thanks for considering a contribution — this repo is a **standard**, so changes to the standard itself carry extra weight. Please read the doctor's constitution first ([`SKILL.md` §2](SKILL.md)): diagnose first, treat second.

## How to contribute

- **Bug reports / red-line violations found in this repo**: open an issue using the Bug template, with evidence (file, line, why).
- **Audit requests**: want this standard applied to a skill of yours? Open an issue with the Skill-audit template and paste your SKILL.md frontmatter.
- **Standard improvements**: propose a change as an issue first, with evidence — measured data beats opinion (see `references/metrics.md` for the honest-measurement rule). PRs without a linked issue will be asked to slow down.

## Style rules

- Surgical patches only: minimal diffs, no full reprints of existing files.
- Every claim should be checkable — cite the file and line, or mark it clearly as opinion.
- Anti-Slop: no filler adjectives, no "revolutionary/seamless/powerful" (see `references/templates.md`).
