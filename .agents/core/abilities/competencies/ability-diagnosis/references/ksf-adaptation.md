# 能力诊断的 KSF 接入说明

本基本功来自 better-skill v1.1.0，Core ID 为 `competency.ksf.ability-diagnosis`，显示名称为“能力诊断”。原版创建、体检、处方和比较方法均保留；正式正文只更换标题并加入 KSF 元数据和资源入口，不使用个人对象的 user_revision。

[完整原仓库](../资料/upstream/)保存固定提交的全部 23 个文件。原文 references/、examples/、assets/ 相对于该目录；裸文件名在其中 references/ 下。逐文件哈希与适配差异见[source-manifest.json](../资料/source-manifest.json)。

原版的对象格式、选择、确认、文件操作、评测和协作要求通过 KSF 及宿主实际能力执行，用户当前指令与已有授权优先。用户明确要求整体重构时可重建目标定义；不因原版的小补丁建议缩减本次范围，也不重复请求已给出的确认。

三项 KSF 设计基本功分别提供协同、搭档和基本功的专业设计体系。它们的专业完整性由各自方法检查；能力诊断提供通用工艺方法。确定性维护通过能力维护和现有程序完成。
