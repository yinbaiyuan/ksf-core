# 方法来源与适配说明

本包借鉴 better-skill v1.1.0 的选型、自由度、渐进披露、阶段退出、检查表、样例及评估闭环组织方式。原版及 MIT 来源保存在[能力诊断资源](../../ability-diagnosis/资料/upstream/)中，固定提交为 f5a82c68eb1d9489b2e3aac3eb46fc8383cd7a93。

本包的专业判断是针对 KSF 对象责任和实际接口建立的原生设计，不声称来自外部专家实验或拥有上游的效果评级。对象身份、版本、引用和派生的程序契约见[对象元数据规范](../../../../docs/对象元数据规范.md)，工作绑定和加载见[context 接口](../../../../docs/cli/context.md)。

examples 和 evals 中的场景、金额和示例身份均有明确评估用途；实际执行结果另保存在任务证据中。案例对方法形成反馈，后续真实使用和独立模型比较沿相同标准积累。

主文及本包明确调用的资源持有专业流程；公共说明不成为隐藏的执行前提。
