# 协同产出模板

归属：协同设计。按复杂度裁剪，不强制每次生成图、表或独立阶段。

## 合作方案

整体结果与成立理由 → 成果/责任/输入/使用方表 → 主结构和关键依赖 → 交接、返回及变化传播 → 协调和整体完成 → 支持缺口与验证题。

# 明确合作名称

## 适用与整体结果
写出合作成立条件及用户需要的整体结果。

## 责任与依赖
用成果说明谁负责、谁接收、需要什么，不只排列角色。

## 交接和返工
写明原件版本、接手条件、问题归属、修改及重新检查。

## 变化和结束
上游变化影响谁，如何保留有效部分，整体何时完成。
~~~

## 关键交接记录

成果原件/版本 → 提供责任 → 接收责任 → 接手条件 → 必须保留的依据与未决 → 返回条件及修订维护方。

## 修订说明

原失败及证据 → 责任/依赖/交接/专业方法的归因 → 合作关系改动 → 未受影响内容 → 复查结果。专业方法缺陷交回原责任，不在协同加一份算法。
