# 项目归档与恢复：过程与交付

本过程属于项目验收与复盘。业务定义在本能力及搭档治理原件中，程序契约在项目治理模型与归档事务实现中；core/docs仅解释。没有实际归档授权时只做分析或预览，已有明确授权不重复询问。不得将“实现归档功能”理解成“归档当前项目”。

## intent：判断封存意图

- 问题：已经做完、决定停止，还是近期不做但以后可能继续？
- 先读：project.md、当前状态及用户本次意图，不从目录杂乱推断项目结束。
- 引导：先给有依据的判断，再问一个会改变选择的问题；已确认的直接复用。
- Agent动作：区分完成、取消、暂停和位置封存。未开始/进行中/待验收先按正常过程完成、取消或暂停，不以归档跳过判断。
- 产物：归档目的、对象与有效授权；暂停保留原环节。
- 退出：封存意图和业务状态一致；否则保留guidance.step=intent和必要待问。

## inventory：盘点工作现场

- 问题：哪些结果已取得，哪些工作尚未结束，恢复时需要知道什么？
- 先读：本层条件、当前任务、成果与证据入口、必要外部操作回执及窗口草稿。
- 引导：帮助区分已验证结果、未决判断和等待回执，不重复总结整段聊天。
- Agent动作：已完成核对有效本层验收与项目复盘；已取消记录停止原因、已有结果和遗留去向；暂停保留进度、原因、恢复条件及next_action，不强制做完成复盘。
- 产物：原件中的当前结果与真实缺口，未知外部动作按原操作ID对账。
- 退出：交付与未决可查，重要外部动作没有被当作已结束。

## handoff：安排遗留

- 问题：哪些不再做，哪些移交，哪些留到恢复时继续？
- 先读：项目复盘或暂停接续点、下级工作及相关依赖。
- 引导：为仍有价值的工作提出承接候选，不自动把灵感转成承诺。
- Agent动作：需要移交的保留原结果来源，承接对象明确责任和验证办法；停止或暂停的按正常状态流程处理，不批量伪造下级完成。
- 产物：遗留去向。取消写入项目复盘，暂停写入项目主文和恢复条件。
- 退出：恢复或下一承接者能找到应继续的事实，其他项目没有因封存丢失依赖。

## impact：检查范围与影响

- 问题：此次仅封存指定项目，还是明确列出一组项目？
- 先读：双向父子关联、跨项目依赖和来源、当前工作绑定、窗口未保存草稿。
- 引导：展示实际影响，不把父项目授权解释为对所有子项目的隐含授权。
- Agent动作：未结束的当前子项目先调整归属，或显式列入批次并逐项满足条件；已结束子项目可以保留原处。父子关系保留，工程原位保留。草稿先保存或明确放弃，保存回执未知时先对账。
- 产物：明确的targets清单、原因和操作者。
- 退出：对象与影响可审阅，未解决事项阻止依赖步骤，不猜选关系。

## preview：预演与条件提交

- 问题：当前原件能否安全封存，实际移动到哪里，哪些引用受影响？
- 先读：公共project archive/restore预览返回的allowed、blockers、warnings、targets和ifMatch。
- 引导：概括业务阻止项及其处理办法，用户已授权且预览通过后继续执行。
- Agent动作：以实际targets、reason、actor预览；提交同一请求并补operationId和ifMatch。预览后有变化就重新核对，不强行覆盖；未知返回按同一操作ID重放对账。请求文件使用结构化JSON，不拼接业务文本到shell。
- 产物：程序回执或明确的冲突/待恢复状态。
- 退出：实际成功，或缺口已清楚保存。中断用recover，恢复归档项目用restore，两者不能混用。

## verify：核验与交付

- 问题：材料完整吗、入口仍可用吗、接手是否准确？
- 先读：提交回执、归档原件、两端关联、文件摘要及受影响会话的当前绑定。
- 引导：说明完成到什么层次，不用程序通过代替用户管理效果。
- Agent动作：核对稳定ID、业务状态、原始字节和证据版本；旧正文不重写，位置经project locate/公共resolve查阅。归档原件只读，引用重定位仅由显式过渡办理。当前对话按最新etag退出执行用途；其他聊天下次恢复识别PROJECT_WORK_ARCHIVED，不能用旧缓存启动工作，不批量修改其绑定或原始聊天。
- 产物：可查的封存结果、必要回执和恢复入口。archive_history持操作事实，详细清单及原字节备份由程序日志保存，不另写重复的归档总文档。
- 退出：实际交付和下一接续清楚。恢复仅回到当前目录并保留原业务状态；再推进时重核目标、现实变化、依赖、证据和下一步，已完成/取消任务不自动重开。

未完成引导沿当前对象guidance保存当前步骤和待问，正文只保存已确认结果与必要入口。里程碑和任务不单独搬出项目归档。小项目可合并展示多个已清楚步骤，判断标准相同。
