# 四类能力对象说明

协同描述跨独立责任的合作，搭档承接持续责任，基本功提供专业判断或稳定操作，数据包提供明确范围的资料。附属资源属于对应对象，不是第五类能力。

设计和维护的方法入口分别是三项设计基本功与能力维护；本页解释概念，不规定另一个建设流程。完整对象格式、版本和引用规则见[对象元数据规范](../../../../docs/对象元数据规范.md)。

## 资料采用约定

能力定义可以引用资料、模板和程序。资料入口、适用范围及缺失处理由实际消费它的能力声明；本页不增加公共元数据或运行步骤。文件链接和能力引用的读取行为见[context CLI](../../../../docs/cli/context.md)。

对象内的方法资源由该基本功明确调用并负责。公共文档说明接口，项目资料和用户事实保留原位置。
