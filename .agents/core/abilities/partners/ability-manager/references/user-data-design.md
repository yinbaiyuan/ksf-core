# 对象数据与设置说明

本页解释既有存储和归属，不承载独立业务流程。字段是否必要、怎样影响行为，分别由协同设计、搭档设计或基本功设计处理；授权保存、删除和数据影响由能力维护处理。

| 内容 | 既有归属 | 示例 |
| --- | --- | --- |
| 对象实际消费的长期偏好 | 对象 user-data | 搭档交付详略、方法的专业选项 |
| 本次明确参数 | 当前输入及交接 | 这次用哪种输出形式 |
| 当前任务进度、成果和证据 | 原任务或项目原件 | 方案稿、检查点 |
| 原生参与、临时变量 | 现有聊天机制 | 原生轮次及对象变量 |
| 程序缓存 | 对应 runtime-data | 正文消费指纹 |
| 凭据 | 实际服务的凭据机制 | 不放普通对象设置 |

Runtime 持有采用时读取、当前指令优先、临时覆盖和恢复规则；user-data 程序提供按完整 ID 存取、版本条件和错误结果。字段描述本身不注册程序 schema。

接口见[user-data CLI](../../../../docs/cli/user-data.md)，可选表达见[字段示例](../templates/object-user-data.md)。本页中的示例均不是当前用户事实。
